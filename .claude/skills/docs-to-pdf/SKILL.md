# Документи → PDF

## Правило
Будь-який звіт/ТЗ/опис, що йде **людині**, конвертувати в PDF. Markdown-оригінал лишати поруч (для себе/історії).

## Як
```bash
python3 /Users/alexandrdybin/Desktop/Стратег/md_to_pdf.py <файл.md> [вихід.pdf]
```
- Кирилиця ок (Arial Unicode), стиль охайний: NAVY-заголовки, смугасті таблиці.
- Підтримує: `# ## ###`, `**жирний**`, списки `- • *`, таблиці `|..|`, `---`, `> цитату`.
- НЕ підтримує: картинки, код-блоки, вкладені списки — спрощувати markdown перед конвертацією.

## Далі
Готовий PDF відправляти через @TMO_team_bot `sendDocument` у відповідну групу (див. скіл post-to-groups).
