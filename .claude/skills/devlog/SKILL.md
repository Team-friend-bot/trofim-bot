# Звід дня в журнал розробок

Папка: `/Users/alexandrdybin/Desktop/Стратег/devlog`

## 1. Зібрати слід

```
python3 bin/collect.py --all && python3 bin/index.py
```

## 2. Визначити день

За замовчуванням — **сьогоднішній**. Якщо у аргументах названо дату — беремо її.
`index.py` виводить `PENDING YYYY-MM-DD` — незведені дні.

## 3. Написати звід

Прочитай `_raw/YYYY-MM-DD.md` і напиши `YYYY-MM-DD.md`.
**Взірець структури й тону — `2026-08-26.md`.** Секції:

- заголовок з датою і рядком статистики
- `## Підсумок одним рядком`
- `## Зроблено` — ✅ фічі, 🐛 фікси, 📊 аналіз; суть, а не команди
- `## Деплої`
- `## Рішення / чому саме так` — **найцінніша секція**, тут причини, не дії
- `## PENDING`
- лінк на сирий слід

Правила: не вигадувати фактів; якщо зі сліду незрозуміло чим скінчилось — так і
написати; писати мовою бізнесу, а не імен файлів.

Якщо звід за цей день уже існує — **доповнити** його новим, не переписувати з нуля.

## 4. Зберегти

```
cd /Users/alexandrdybin/Desktop/Стратег/devlog && python3 bin/index.py && git add -A && git diff --cached --quiet || git -c user.email=666dyba@gmail.com -c user.name=TROFIM commit -qm "devlog: звід за $(date +%F)"
```
